# PayMate - Modern FinTech & UPI Payment Android Application

PayMate is a state-of-the-art, beautifully designed Android payment application inspired by top Indian UPI platforms like PhonePe, Google Pay, and Paytm. Built with modern Android development practices, custom XML drawables, vector assets, and clean Kotlin architecture.

## 📱 Features

- **Quick UPI Transfers**: Instant money transfers via QR code, contact search, bank account, and self-transfer.
- **Recharge & Bill Payments**: Mobile recharge, electricity, DTH, fastag, loan repayments, and broadband.
- **Financial Services**: Credit score check (CIBIL), digital gold investment, insurance, and personal loans.
- **Rewards & Cashback**: Interactive promotional banners, scratch cards, referral rewards, and exclusive deal tags.
- **Sleek Dark Theme UI**: Custom rounded squircle shapes, vibrant gradient cards, smooth scrolling, and floating glassmorphism bottom navigation.

## 🛠 Tech Stack & Tools

- **Language**: Kotlin 2.0.21
- **Min SDK**: 24 (Android 7.0) | **Target SDK**: 35 (Android 15)
- **UI Architecture**: ViewBinding / XML Layouts with custom shape drawables and vector assets
- **Build System**: Gradle 8.11 with Kotlin DSL

## 🚀 Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/Priyankkhatri/PayMate.git
   ```
2. Open the project in **Android Studio (Ladybug or newer)**.
3. Sync Gradle dependencies.
4. Run on an Android Emulator or physical device (Android 7.0+).
